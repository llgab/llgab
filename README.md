## Projetos em destaque / Featured Projects

### StockFlow

**StockFlow** é uma aplicação web full-stack desenvolvida como projeto de portfólio, simulando um sistema moderno de gerenciamento de estoque para empresas de varejo de tecnologia.

O projeto combina uma **interface administrativa responsiva em React e TypeScript** com uma **API REST desenvolvida em FastAPI**, utilizando **PostgreSQL** como banco de dados.

Entre as funcionalidades estão gerenciamento de produtos e categorias, controle de estoque, movimentações de inventário, paginação, filtros, busca por produtos e suporte a **inglês e português**.

> Todos os produtos, categorias e dados utilizados no projeto são fictícios e foram criados exclusivamente para fins de demonstração.

<div align="center"> 
  <p>· · ·</p> 
</div>

**StockFlow** is a full-stack web application developed as a portfolio project, simulating a modern inventory management system for technology retail businesses.

The project combines a **responsive React and TypeScript administrative interface** with a **REST API built with FastAPI**, using **PostgreSQL** as the database.

Features include product and category management, inventory control, stock movements, pagination, filtering, product search, and **English/Portuguese language support**.

> All products, categories, and data used in the project are fictional and were created exclusively for demonstration purposes.
