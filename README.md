## Projeto em destaque / Featured Project

### OdontoCare

**OdontoCare** é uma aplicação web full-stack desenvolvida como projeto de portfólio, simulando o ambiente digital de uma clínica odontológica moderna.

O projeto combina um **site institucional responsivo** com um **sistema dinâmico de gerenciamento de conteúdo (CMS)** desenvolvido do zero.

> Todos os dados e informações utilizados no projeto são fictícios e foram criados exclusivamente para fins de demonstração.
